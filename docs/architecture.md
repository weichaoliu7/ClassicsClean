# ClassicsClean 架构与算法说明

本文是 README 的「深水区」：讲清楚**代码怎么分层、数据怎么流动、参数为什么是这些值**。
读完 README 想改代码或调参时，看这一篇。

---

## 1. 分层

代码只有 4 层，依赖方向严格自顶向下（第 1 层不依赖第 4 层，反过来也不行）：

```
第 4 层  入口层   src/classicsclean/apps/
                     cli.py   命令行：批处理 / 无头 / 环境自检
                     gui.py   图形界面：拖拽 / 选择文件 / 实时进度
                         │  两者都只调用 process_pdf，不重复任何算法逻辑
第 3 层  编排层   src/classicsclean/pipeline/
                     page.py      单页流水线（纯数组 -> 纯数组）
                     document.py  整本流水线（唯一的 IO 边界：读 PDF / 写 PDF）
                         │
第 2 层  算法层   src/classicsclean/algorithms/
                     masks.py        掩膜分割：白边 / 墨迹 / 破洞 / 纸面
                     white_point.py  白场估计：最白区 · 局部白场 · 兜底
                     tone.py         色调映射 + 文字保护
                     repair.py       破洞修补
                         │
第 1 层  基础层   src/classicsclean/config.py    参数唯一来源
                 src/classicsclean/imaging.py   PDF ↔ 位图、灰度化、JPEG2000
                 src/classicsclean/morphology.py 形态学 / 滤波 / 重采样原语（纯 numpy）
```

**分层原则**

- 第 1、2 层只吃 numpy 数组、吐 numpy 数组：不接触文件、不接触界面，所以可以单测到像素级。
- `morphology.py` 是第 1 层的「无状态数组算子库」：膨胀 / 腐蚀 / 闭运算 / 极大值 / 均值 / 高斯 /
  中值滤波 / 连通域标记 / 漫水填充 / 面积缩放，全部用纯 numpy 实现，与 OpenCV 逐像素等价
  （`tests/unit/test_morphology.py` 对照，cv2 未安装时自动跳过）。这是 exe 体积从 99 MB 降到
  36 MB 的关键——opencv-python 的二进制超过 110 MB，而本项目只用到这几个算子。
- 第 3 层 `pipeline/document.py` 是全项目唯一读写 PDF 的地方；任何调用方都不该自己拼装 PDF。
- 第 4 层只是同一套算法的两种入口。`apps/__init__.py` 延迟导入 tkinter，
  因此命令行模式下完全不触碰 GUI 依赖。

## 2. 命名约定

| 对象 | 约定 | 例子 |
|------|------|------|
| 源码 / 测试 / 脚本 / 目录 | 全小写 ASCII，用 `/` 分层表达职责 | `algorithms/white_point.py` |
| 面向用户的产物后缀 | 保留中文，便于一眼看出用途 | `xxx_清洁版.pdf` |
| 报告文件 | ASCII 文件名，内容中文 | `reports/test-report.md` |
| 模块内常量 | 语义命名，注释紧跟其后 | `FALLBACK_DPI = 200` |

原因：工程内的名字会被 shell、CI、打包工具反复解析，非 ASCII 字符在跨平台时容易出问题；
而交付给用户的文件名只在本机资源管理器里出现，中文更直观。

## 3. 单页数据流

```
源页面位图 (RGB uint8)
    │
    ├─ 1. compute_masks ──────→ 白边 / 墨迹 / 破洞 / 纸面（四者互斥且覆盖全图）
    ├─ 2. whitest_region ─────→ 基线白点 Wp（纸面最白连通区域的均值）
    ├─ 3. resolve_white_field → 白场图 Wp_map（逐像素）+ 基线白场 Wp_full
    ├─ 4. tone_map ───────────→ 亮度拉平 + gamma 高光压缩（纸面推向白）
    ├─ 5. text_guard ─────────→ 笔画恢复为「基线白场 + 线性映射」（字不动）
    └─ 6. repair_holes ───────→ 只补不涉及文字的破洞
    │
输出灰度图 (uint8) ──→ encode_jp2 ──→ 成品 PDF 页面（DeviceGray + JPXDecode）
```

关键点：**第 4 步可以任意压白，第 5 步把字原样还原**。这两步的组合就是
「纸面白、字不动」的全部秘密。

## 4. 四条红线（不可违反）

| # | 红线 | 守护者 | 单元测试 |
|---|------|--------|----------|
| 1 | 纯白扫描边输出恒为 255 | `tone.tone_map` | `test_tone_map_margin_is_pure_white` |
| 2 | 笔画及抗锯齿边缘**逐像素**等于「基线白场 + 线性映射」，差必须为 0 | `tone.text_guard_weight` | `test_text_guard_keeps_strokes_identical` |
| 3 | 白场只统计纸面，与白边 / 墨迹 / 破洞的重叠像素恒为 0 | `white_point.whitest_region` | `test_whitest_region_never_touches_excluded_areas` |
| 4 | 碰字的破洞一律不补 | `repair.repair_holes` | `test_hole_touching_text_is_skipped` |

红线 2 的实现细节值得单独说：文字保护区用
`np.maximum(inner, GaussianBlur(outer))` —— **内圈硬取 1，绝不羽化**。
历史上曾对内圈也做羽化，结果权重永远到不了 1，字被轻微改动；这个坑由此沉淀成一条断言。

## 5. 算法要点

1. **只取内嵌主图像。** 扫描古籍常在图像之上叠加 OCG 馆藏章水印层，整页渲染会把水印混进来。
   `imaging.page_image` 取该页面积最大的内嵌图像；没有内嵌图像（纯文本页 / 矢量页）时
   退化为 200 dpi 整页渲染。

2. **四掩膜互斥。** 白边 = 与图像边缘连通的亮区（floodFill）；墨迹 = 灰度低于
   `0.62 × 非白边中位`；破洞 = 图像内部的孤立亮块（面积 30px ~ 整页 3%）；其余是纸面。
   所有统计只在纸面上做，指标才不会被白边 / 字 / 洞污染。

3. **局部白场（定稿关键）。** 线装纸的黄变与霉斑是**空间非均匀**的：实测约 45% 纸面像素
   比全局最白区暗 12 灰阶以上，单一全局白点在数学上不可能同时把亮区与暗区推到白。
   改用多尺度（31 / 61 / 121）局部纸面亮度场作逐点白点，由粗到细逐级细化：
   窗口内纸面样本不足时回退到上一级更粗的估计。

4. **gamma 3.0 高光压缩。** 只调整映射曲线，白点规则保持不变，把残留底灰推向纯白。
   `d = (Wp - gray) / (Wp - bp)`，`out = 255 × (1 - d^3)`。

5. **文字硬保护。** 笔画 + 抗锯齿边缘权重恒为 1，输出直接沿用基线白场的线性映射
   （真书实测差 = 0）。注意基线必须是**全局** Wp_full：若用局部白场做基线，
   字的映射会随邻域漂移。

   **低对比晕边扩展（v1.2 起）。** 木版印刷的洇墨晕边只比纸面暗 20-60 灰阶，
   全局墨迹阈值（`ink_ratio × 中位`）套不住，会被 gamma 漂白成「文字偏浅」。
   所以保护掩膜在墨迹之外，还纳入「比局部纸面亮度场暗超过 `text_dev_thr`（默认 15）
   的像素」；参照场用多尺度 `bg_field`，并迭代剔除候选去除晕边对参照的污染。
   阈值需明显高于扫描噪声（约 3-6 灰阶），否则纸面纹理会被误保护。

6. **JPEG2000 52 dB。** 45 dB 时字核心编码噪声达 42 灰阶，50 dB → 10，
   52 dB → 16 以内且体积可控，所以定 52 dB。

7. **强色偏兜底。** 纸面亮度低于 200（深红封面之类）时，白场退化为
   「局部均值 + 0.8 × 局部标准差」，保证背景仍读作白色。

## 6. 参数唯一来源：`config.Params`

所有常量集中在一个 frozen dataclass 里，构造时即校验，非法值直接抛 `ValueError`。
改一个数字就能整体调整效果，改之前请读完这一节。

### 掩膜分割

| 字段 | 默认 | 含义 |
|------|------|------|
| `margin_thr` | 235.0 | 纯白边种子亮度阈值 |
| `ink_ratio` | 0.62 | 墨迹判定：`gray < 0.62 × median(非白边)` |
| `hole_thr` | 225.0 | 破洞亮度阈值 |
| `hole_min_area` | 30 | 破洞最小面积（像素） |
| `hole_max_frac` | 0.03 | 破洞最大面积（占整页比例） |

### 白场估计

| 字段 | 默认 | 含义 |
|------|------|------|
| `min_area_frac` | 0.008 | 最白区面积下限（整页 0.8%），不足则自动扩大候选集 |
| `wp_mode` | `"local"` | `local` 局部纸面场 / `whitest` 全局最白区 / `p50…p75` 纸面分位 |
| `bg_wins` | (31, 61, 121) | 局部白场的多尺度窗口（由粗到细） |
| `outlier_k` | 2.5 | 白区均值上限 = 纸面均值 + k × 纸面标准差；超过视为破洞 / 高光噪点 |
| `safeguard_level` | 200.0 | 纸面亮度低于此值触发兜底白场 |
| `safeguard_win` | 61 | 兜底白场统计窗口边长 |
| `safeguard_k` | 0.8 | 兜底白场 = 局部均值 + k × 局部标准差 |

### 色调映射

| 字段 | 默认 | 含义 |
|------|------|------|
| `gamma` | 3.0 | 高光压缩指数（1.0 = 线性，不压缩） |
| `text_guard` | 1 | 文字保护：int = 笔画膨胀半径；`("dev", T)` = 按偏离局部纸面的幅度软判定 |
| `text_guard_sigma` | 1.5 | 保护区外圈羽化 sigma（内圈恒为 1） |

### 可选增强与编码

| 字段 | 默认 | 含义 |
|------|------|------|
| `lift` | 0 | 局部背景抬平迭代次数（已由局部白场取代，默认关闭） |
| `ink_protect` | 3 | `lift` 生效时的文字保护半径 |
| `repair_holes_enabled` | True | 是否修补不涉及文字的破洞 |
| `jp2_db` | 52.0 | JPEG2000 质量（dB） |
| `jp2_num_resolutions` | 6 | JPEG2000 分解层数（小图自动下调） |
| `validate` | False | 出片后是否回读校验（耗时约翻倍） |

## 7. 输出 PDF 规格

每页只有一张图像 XObject：

```
/Subtype        /Image
/ColorSpace     /DeviceGray
/BitsPerComponent 8
/Filter         /JPXDecode        （JPEG2000，不可逆，以 dB 指定质量）
```

页面 `MediaBox` 完全沿用源文档，因此版式、开本、页边距逐页一致。
元数据写入 `dc:title = <源文件名>（白底清洁版）`。

## 8. 性能与内存

- 逐页处理后把 JPEG2000 码流**落到临时目录**，装配 PDF 时再读回：
  大部头书籍不会把整本书的码流压在内存里。
- 单页处理时间与像素数近似线性；真书 48 页（约 2000×3000 px/页）在普通笔记本上约 1 分钟。
- `--validate` 会重算一遍算法并重新渲染成品 PDF，耗时约等于处理时间。
