# samples/ —— 测试样本

本目录存放**验收用的真实扫描件**。单元测试不依赖这里（用的是合成页），
只有全书终检（`pytest -m slow` / `python scripts/run_acceptance.py`）才会读取。

| 文件 | 作用 | 来源 |
|------|------|------|
| `shenglv-qimeng.pdf` | 源扫描件，48 页，13.09 MB | 原文件名：`NCL-002940398_聲律啟蒙_【三卷_(清)車萬育著_;_(清)夏大觀刪補_;_(清)王之幹箋釋】.pdf` |
| `shenglv-qimeng_清洁版.pdf` | 成品样本（**由代码生成，可随时重建**） | `python scripts/run_acceptance.py` 会自动重建 |

说明：

- 成品样本只是「最近一次终检的产物」，不是需要手工维护的资产；
  缺失时终检会现场用当前代码重新生成，因此它永远与代码同步。
- 文件名采用「ASCII 主名 + 中文后缀」：`_清洁版` 是 CLI / GUI 的默认输出后缀。
- 源样本是泛黄、带霉斑与背面透字的线装书扫描件，正是本工具的目标场景。
